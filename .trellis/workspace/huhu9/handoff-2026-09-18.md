## 4. Codex / godot-ai 连接问题（已解决，结论重要）

用户给 Codex 也配了 godot-ai，但一直连不上。排查结论：

- **架构**：Godot 插件自己托管一份服务（`godot-ai --transport streamable-http --port 8000 --ws-port 9500`），AI 客户端各自 spawn 一个 `godot-ai attach` 桥去连它
- **HTTP 端点需要 Bearer 令牌**，令牌在 `%LOCALAPPDATA%\godot-ai\capabilities\http-8000.json` 的 `http` 字段；**每次服务重启令牌都会变**
- **根因是网络层（梯子），不是 Codex 配置。** 当时 `aihub.top` 被 DNS 解析成 Facebook 的假地址（`128.242.245.29` / `31.13.94.49`），现在已恢复正常（`39.109.122.128`）
- **教训**：`curl` 的测试结果**代表不了 Codex**（两者走代理/隧道的路径不同），不要拿 curl 当裁判

**唯一真正该修的配置错误**：Codex 配置里 `pythonw.exe` 的路径。正确的是
`C:\Users\huhu9\AppData\Local\Python\pythoncore-3.14-64\pythonw.exe`
（不是 `...\Programs\Python\Python314\pythonw.exe`）。

## 5. 本项目上踩过的坑（省得重踩）

1. **`SceneManager._ready()` 会在「初始场景还没就绪」时就调用它的 `init()`。** 实测那一刻 `is_inside_tree()` 已经是 `true`，但 `is_node_ready()` 还是 `false` —— 所以场景控制器里**不能用 `@onready` 存子节点引用**，要用 `get_node_or_null()` 在 `init()` 里解析。判据必须是 `is_node_ready()`。已写进 `.trellis/spec/frontend/state-management.md`。
2. **Godot 的 `ResourceSaver.save()` 在非编辑器上下文会丢掉全部 `uid` 属性。** 批量改 `.tres` 别用它，要手改文本或事后补 uid。
3. **运行 Godot 编辑器会把 `.cs` 缩进从空格改成 Tab**（违反 `.editorconfig` 的 `indent_style = space`）。用户已明确说「格式改了就改了吧，不用管」。
> **2026-09-19 补注（当前仓库已更新，下面第 4/5/6 条仍然成立，但只对已经废弃的命令行有意义）**：
> 本次会话已把项目的验证约定统一改成**编辑器 MCP**，所有 `godot-mono --headless` 开关（`--check-only` / `--build-solutions` / `--scene` / `--script`）整体作废。因此：
> - 第 4 条：不用再讨论 `--check-only` 是否有效——该开关已不在工具链里，语法检查不作为门禁。
> - 第 5 条：结论仍重要——**依赖 C# autoload 的场景必须在真实游戏进程里验证**，现在的做法是编辑器 MCP 的 `project_run` + `logs_read(source="game")`。
> - 第 6 条：结论不变——`--build-solutions` 会失败，C# 编译一律 `env CI=true dotnet build CUSGA.sln --no-restore`。
> 权威说明见 `AGENTS.md` 第 1 节与 `.trellis/spec/frontend/quality-guidelines.md`。

4. **`--check-only` 对引用了 autoload 的 GDScript 无效**（会报 `Identifier not found: <AutoloadName>`）。别把它的失败当回归。
5. **`--script` 模式下 C# autoload 不可用**，依赖 autoload 的场景只能用 `--scene` 跑真实游戏进程（现等价做法：编辑器 MCP 的 `project_run`）。
6. **不要用 `--build-solutions`**（本机 4.6.3 命令行与 `addons/godot_ai` 要求 4.7.1 冲突会失败）。C# 编译直接 `env CI=true dotnet build CUSGA.sln --no-restore`。
7. **Button 的 `focus` 样式会叠画在按钮上**，指向同一张贴图会渲染出双重边框 —— 用 `StyleBoxEmpty`。
8. **`dotnet run --project tests/CUSGA.Tests` 在本机跑不起来**（GodotSharp 在 Godot 之外解析不了）。C# 规则层要真正执行，得改写成 Godot runner（参考 `tests/godot/shop_trade_tests.gd` 的写法）。

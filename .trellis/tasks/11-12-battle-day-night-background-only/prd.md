# 战斗昼夜滤镜只作用于背景

## 背景

战斗场景的昼夜滤镜当前以 `z_index = 1500` 位于默认 canvas，覆盖了卡牌、怪物卡、玩家等世界内容；只有 `UI` / `Button`（`z_index = 2000`）在其上方。夜晚进入战斗时，卡牌与怪物卡会被整体压暗，影响可读性和操作判断。

## 目标

- 战斗场景中的昼夜颜色只渲染在背景之上。
- 卡牌、怪物卡、玩家、掉落物、战斗 HUD 等可交互内容不得被时间颜色覆盖。
- 探索场景的既有昼夜表现不变。

## 验收标准

1. 战斗场景的 `DayNightFilter` 层级低于卡牌常态层级（`CARD_Z_INDEX_NORMAL = 1`），高于战斗背景。
2. 战斗背景（包含运行时复制的 `MapBackground`）位于滤镜之下，确保背景仍被染色。
3. 卡牌、怪物卡、玩家、掉落物与 `UI` / `Button` 仍位于滤镜之上。
4. `day_night_filter_contract` 新增战斗层级契约测试并通过。
5. 运行时启动战斗场景，读取滤镜、背景、卡牌/怪物的实际 `z_index`，并用截图确认夜晚卡牌不被压暗。
6. 不改变探索场景 `Main.tscn` 的 `CanvasLayer` 分层策略与滤镜颜色曲线。

## 非目标

- 不修改昼夜颜色、阶段进度、过渡时间或 `TimeSystem` 状态。
- 不调整卡牌自身的常态/悬停层级常量。
- 不重构战斗场景的相机或 HUD 节点树。

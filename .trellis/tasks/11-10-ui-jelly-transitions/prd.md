# UI 自然动态过渡

## Goal

保留现有 UI 过渡接入，按最新反馈改为轻量、多种自然效果，保持业务和布局。

## Requirements

- 最新补充需求：“能否把这个功能单独抽离出来，方便以后直接用”。提供独立可复用的过渡组件、检查器配置和接入示例，保留当前自然效果及旧路径兼容。

- 最新用户原话：“有些太晃眼睛了，能不能多做一些其他效果？正常一点。”此前批准的强果冻表现由本轮反馈替代。
- 接入登录主界面、仓库、商店、背包、合成、大地图、设置与暂停面板的进入/退出。
- 主菜单、仓库、合成轻微上浮；商店短距离侧滑；背包与设置轻微等比缩放；大地图和暂停菜单淡入淡出。取消大幅拉伸、压扁和往复回弹。
- 打开 0.18～0.24 秒，仓库组间延迟 0.015 秒（共 0.285 秒），关闭 0.14 秒；缩放幅度不超过 2%，平移不超过 16 个视口像素。
- 保持现有美术、布局、节点路径、库存交易、存档、地图画布缩放及业务架构。
- 连续快捷键切换不叠动画、不执行过期关闭回调；缓存重入恢复原位置、比例与颜色。
- 地图/暂停的动效在暂停时继续推进；关闭完成后只归还自己造成的暂停。
- 动画期间防误交易、拖动与穿透；必要跨界面请求在退场完成后执行并保留数据校验。
- 不修改生态地图、图集、战斗过场或玩家数值；不提交推送。

## Acceptance Criteria

- [x] 过渡实现位于独立目录，无 CUSGA 业务/Autoload 依赖，可整目录复制复用。
- [x] 新界面可拖入组件场景，在检查器选择目标及效果，再通过原公开入口播放。
- [x] 旧入口仍可加载，现有各界面的参数与生命周期不变；新旧入口及示例通过 Godot 验证。

- [x] 游戏中看到各界面不同的平缓过渡，中间帧无非等比拉伸、回弹或缩放超调。
- [x] 登录→仓库→商店→仓库→登录循环无黑屏、重复入场或输入残留。
- [x] 背包、合成、地图与暂停界面能打开、关闭并连续反向切换。
- [x] 暂停期间动效完成、收尾状态正确，原生业务回归通过。
- [x] 原位置/比例/透明度复原，Tooltip/拖动与焦点正确收尾。
- [x] 本轮 Godot 4.7.1 编辑器检查与运行验证无新增阻塞错误，文档参数同步。

# 开局技能卡抽取（抽5选2）

## Goal

开局触发技能卡抽取流程：从可用技能卡池随机抽 5 张展示给玩家，玩家选择其中 2 张并获取（进入背包或出战卡组），其余 3 张丢弃。需要抽取逻辑、选卡界面与随开局流程的触发时机。验收：每次开局恰好抽 5 张、只能选 2 张、选定后确实进入玩家持有物、未选中不残留。

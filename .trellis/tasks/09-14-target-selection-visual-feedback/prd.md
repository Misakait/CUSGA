# 目标选择视觉反馈

## Goal

在玩家使用需要指定目标的卡牌时，清晰区分可选、悬停、主选中、次级选中与不可选目标，降低误选并让多目标选择的优先级可见。

## Requirements

- R1：在点击与拖拽模式中，为所有敌人怪物卡计算并呈现可选、悬停、主选中、次级选中或不可选状态。
- R2：需要手动指定目标时，可选但尚未选中的目标显示轻微放大与循环呼吸缩放。
- R3：鼠标悬停在可选且未选中的目标上时，显示比呼吸态更明显的放大反馈。
- R4：主选中目标显示最大的选中缩放倍率与绿色边框，且不再播放呼吸动画。
- R5：次级选中目标显示小于主选中目标的选中缩放倍率与绿色边框。
- R6：全体敌人、随机敌人与全体单位卡将所有受影响的敌人显示为自动选中的绿色边框状态。
- R7：自身目标卡将所有敌人怪物卡变暗，不新增玩家血量、能量或属性 UI 的目标标记。
- R8：拖拽模式在悬停合法目标时预览主/次目标的绿色选中状态；点击模式在实际点击目标后保持该状态。
- R9：视觉状态切换不应改变既有的目标合法性、选中顺序、随机结果、能量消耗或出牌结算规则。

## Acceptance Criteria

- [ ] 使用需要手动指定目标的卡牌时，所有合法且未选中的敌人目标都会出现轻微的循环呼吸缩放效果。
- [ ] 将鼠标悬停在合法且未选中的目标上时，该目标会明显放大；离开后恢复到可选目标的呼吸状态。
- [ ] 选定主目标后，该目标保持最大选中缩放、显示绿色边框，并停止呼吸缩放。
- [ ] 选定多个目标时，次级目标显示绿色边框，且缩放倍率小于主目标。
- [ ] 使用仅能指定己方的卡牌时，敌方目标均变暗，己方合法目标不会变暗。
- [ ] 使用全体敌人、随机敌人或全体单位卡时，所有受影响的敌人均显示绿色边框且不播放呼吸缩放。
- [ ] 取消或结束目标选择后，所有目标恢复到原有的非选择视觉状态。

## Background

- `scripts/card_scripts/card_manager.gd` 已统一计算卡牌目标范围，并同时服务点击与拖拽操作模式。
- `entities/Monster.cs` 已提供不缩放血条的怪物卡面缩放接口；当前没有边框、呼吸动画或不可选目标变暗状态。
- 现有目标类型为自身、单体敌人、全体敌人、任意单体、全体单位、随机敌人与扩散敌人。
- 自身施放以点击空白处或确认时的 `PlayerManager` 作为默认目标，玩家场景没有可缩放、可描边的战场卡面。
- 现有自动化测试覆盖目标类型与结算，但没有覆盖 `CardManager` 的目标选择表现。

## Out of Scope

- 不新增玩家血量、能量或属性 UI 的目标边框、缩放或呼吸动画。
- 不改变卡牌目标合法性、目标解析、随机结果、出牌确认、能量消耗或战斗结算规则。

# Battle operation mode

## Goal

为 `battle` 场景提供可切换的卡牌操作模式，使玩家可以选择“点击”或“拖拽”方式施放卡牌；默认使用更适合常规操作的点击模式。

## Confirmed facts

- 现有卡牌选目标方式为拖动卡牌。
- `battle` 场景右上角需要新增“设置”按钮，点击后可切换操作模式。
- 可用模式为“点击”和“拖拽”。
- 新开局或没有已保存偏好时，默认模式为“点击”；用户选择的模式必须跨战斗、跨重启保存。
- 点击模式的操作顺序为：点击要使用的卡牌，再点击目标；若不点击敌人作为目标，则以玩家自身为目标。
- 点击模式使用显式确认：选择卡牌后可点击敌人选择目标；点击“确定”施放当前卡牌，未选择敌人时以玩家自身为目标；点击“取消”放弃本次选择且不消耗卡牌。
- 现有项目中未找到可复用的操作设置持久化实现（`ConfigFile`、`user://` 或设置保存逻辑）。
- 操作模式是跨战斗、跨重启的玩家偏好；需要以通用本地配置文件/设置持久化机制保存。

## Requirements

1. 在 `battle` 场景右上角提供一个设置入口，并在其中清晰显示和切换两种操作模式。
2. 将现有“拖动卡牌选择目标”的行为定义为“拖拽”模式，切换到该模式后保持原有交互。
3. 新增“点击”模式并作为默认值：先选择卡牌，再选择目标。
4. 点击模式下，未选择敌人目标时必须以玩家自身为目标施放卡牌。
5. 点击模式下，在手牌区正上方提供“确定”和“取消”按钮；仅在已选择卡牌时显示。
6. 新增可复用的本地配置持久化机制，用于保存用户设置；操作模式是其首个设置项。
7. 模式切换不能破坏战斗中已有的卡牌使用、目标判定或回合流程。

## Acceptance Criteria

- [ ] 打开 `battle` 场景时，右上角可见并可操作“设置”按钮。
- [ ] 设置界面可在“点击”与“拖拽”模式之间切换，并能明确反映当前选择。
- [ ] 默认进入战斗时使用“点击”模式。
- [ ] 用户切换模式后，下一次进入战斗及重启游戏后仍使用该模式。
- [ ] 本地设置文件不存在、内容缺失或损坏时，系统会安全回退到“点击”模式。
- [ ] 持久化机制可按“分组 + 键 + 默认值”读取和写入基础设置，而不是只为操作模式硬编码文件读写。
- [ ] 点击模式可通过“点击卡牌 → 点击敌人”向被选敌人施放卡牌。
- [ ] 点击模式的“确定”与“取消”按钮位于手牌区正上方，且仅在选择卡牌后显示。
- [ ] 点击模式可通过“点击卡牌 → （可选）点击敌人 → 点击确定”向被选敌人施放卡牌。
- [ ] 点击模式可通过“点击卡牌 → 不选择敌人 → 点击确定”向玩家自身施放卡牌。
- [ ] 点击“取消”会清除卡牌与目标选择、恢复高亮且不会消耗能量或移除卡牌。
- [ ] 拖拽模式仍通过拖动卡牌选择目标，并保持现有行为。
- [ ] 模式切换后不会留下错误的卡牌选中、目标高亮或战斗输入状态。

## Scope

包含战斗场景 UI、卡牌输入处理及通用本地设置持久化；不包含新增卡牌效果、敌人 AI、战斗数值或其他场景的设置入口。

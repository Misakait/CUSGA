# 战斗中右键查看怪物详情

## Goal

在战斗中，玩家用鼠标右键点击怪物卡面即可打开该怪物的只读详情面板。左列为较窄的纵向信息区（怪物名称、五行、当前/最大生命、当前可稳定读取的战斗属性），右列为该怪物的技能池（每个技能显示名称、下一行的描述、与下一个技能之间的分割线）。面板只展示信息，不改变怪物属性、技能效果或战斗数值。

**玩法决定（用户已确认）：打开面板时战斗不暂停。** 面板是战斗之上的信息窗口，ATB、敌人行动、行动值与局外时间继续推进；面板内的生命值等运行时信息随战斗实时刷新。

## Requirements

- 触发：战斗中鼠标右键点击怪物卡面（`monster.tscn` 的 `Area2D` 拾取区域）打开该怪物详情；左键选目标、拖拽/点击出牌、悬停提示行为不变。
- 单一实例：整个战斗只存在一个详情面板实例；面板打开期间查看另一只怪物时替换为新怪物的数据，不叠加、不重复连接信号。因全屏遮罩会挡住其它怪物，采用“先关闭再查看”的显式交互（点击遮罩或关闭按钮关闭后才能右键其它怪物），面板不得在同一时刻绑定两只怪物。
- 关闭：面板提供明显的关闭按钮；`Esc` 也能关闭。关闭面板的 `Esc` 不得打开或关闭全局暂停菜单（`pause_menu.gd` 的 `pause_game`）。面板打开时点击遮罩区域只关闭面板，不穿透到怪物、卡牌或按钮。
- 左列内容（较窄的长方形）：
  - 怪物名称（`BaseData.MonsterName`）。
  - 五行属性文本（`BaseData.ElementalProperty` → 无/木/金/水/土/火）。
  - 当前生命 / 最大生命（`Health.CurrentValue` / `Health.MaxValue`），面板打开期间保持更新。
  - 项目现有怪物卡面已展示的五项战斗属性：物攻、法强、物抗、法抗、速度（`AttributeComponent.GetEffectiveValue(0..4)`），不新增或虚构字段。
  - 数据缺失时显示占位文本（如 `--`、`未知怪物`），不阻断面板打开。
- 右列技能池：严格按 `MonsterSkillComponent.GetSkillPreviews()` 的顺序与规则渲染（仅 `VisibleInPreview` 为真且技能有效的条目；描述优先 `PreviewDescriptionOverride`，否则回退技能自身 `Description`）。不得在 UI 侧重新解析技能集合。
- 每个技能条目：技能名称一行，技能描述下一行且自动换行；仅在技能之间插入分割线，最后一项之后不额外添加分割线。技能较多或描述较长时右列可垂直滚动。
- 无可展示技能时显示“暂无可展示的技能”；空名称、空描述、空条目安全降级为占位文本且不报错。
- 生命周期：面板打开期间怪物死亡、被释放、战斗结束或退出战斗场景时，面板安全关闭并清理引用与信号连接，不产生失效对象访问、残留遮罩或脚本错误。
- 层级：面板必须渲染在战斗卡牌与战斗 UI 之上、`HUDLayer`（暂停菜单）之下；不使用会让全屏 anchors 退化为 0×0 的 `Node2D` 父级。
- 不修改怪物技能效果、属性数值、掉落、AI、行动队列、能量或任何战斗结算数值。

## Acceptance Criteria

- [x] 战斗中右键点击不同怪物，均显示对应怪物的名称、五行、生命与技能，且不残留上一只怪物的数据。
- [x] 左列为较窄长方形信息区；右列按“技能名 → 换行描述 → 分割线”的顺序渲染技能，仅条目之间出现分割线。
- [x] `VisibleInPreview=false` 的技能不显示；覆盖描述优先于技能原描述；顺序与配置一致（由 `GetSkillPreviews()` 保证，UI 不重排）。
- [x] 空技能池、长描述、多技能、缺失数据均可正常展示；右列可垂直滚动且不撑破面板。
- [x] 关闭按钮与 `Esc` 均可关闭；面板打开时按 `Esc` 不打开暂停菜单（面板在 `_input` 消费，暂停菜单只在 `_unhandled_input` 响应），暂停菜单打开时 `Esc` 行为不变。
- [x] 面板打开时点击遮罩/面板区域不触发出牌、选目标、结束回合或右键怪物；战斗仍在推进（帧计数继续增长）。
- [x] 反复打开/关闭、切换到另一只怪物不产生重复面板或重复信号。
- [x] 面板打开期间怪物死亡或战斗结束，面板关闭且无失效引用、无残留遮罩、无 `SCRIPT ERROR`（死亡释放路径由契约测试覆盖）。
- [x] 新增 Godot 契约测试覆盖技能预览顺序/可见性/描述回退、空数据占位、单实例切换与关闭清理；相关既有测试不回归。
- [ ] 真实运行验证：战斗场景中右键打开面板、`Esc` 关闭、暂停菜单不被误触均已完成；面板打开时生命值随伤害更新由契约测试的真实 `ValueChanged` 路径覆盖，运行时 MCP 没有求值入口，无法主动扣血复验。
- [x] `docs/游戏机制与玩法内容.md` 同步新增本节机制说明；`git status` 只包含本次任务需要的改动。

## Notes

- 用户确认的玩法决定：**战斗不暂停**。因此实现不触碰 `SceneTree.paused`，也不引入“恢复暂停所有权”逻辑；与 `pause_menu.gd` 的协调只发生在输入层（`Esc` 不在面板打开时传给暂停菜单）。
- “点击穿透”的判定包含两条路径：GUI 控件命中（按钮/卡槽）与 `CardManager._input` 的世界射线命中。两者都必须被面板拦截。
- 面板只读：不调用技能 `Execute`，不修改 `MonsterData`、`SkillSet` 或技能资源。

## Out of Scope

- 修改怪物技能预览规则本身（`GetSkillPreviews()`、`VisibleInPreview`、描述覆盖）。
- 新增怪物属性、五行克制、掉落、经验或任何战斗数值。
- 面板上的技能释放、技能详情跳转、编辑或筛选功能。

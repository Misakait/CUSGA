# 执行

1. 依赖检索并加载前端规范，核对全部格子与 Controller 消费入口。
2. trellis-implement 完成格子取消与必要控制器连线，覆盖全部区域，维护中文说明与直接关联文档。
3. 主会话通过 Godot MCP scan、四场景真实输入、关键拖动/交易/合成回归验证；保护当前存档并在测试后恢复。
4. trellis-check 对全范围复核并修复，主会话按修改补充必要验证。
5. 总结根因与测试缺口，更新组件规范和机制汇总；git diff --check，重新 git status/log。

只通过 Godot 4.7.1 编辑器验证。不运行 CLI Godot 或 dotnet。不得关闭编辑器。不提交/推送；提交仍需项目规定的逐文件报告和用户明确同意。

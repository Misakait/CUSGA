# 快捷装备与技能卡交互

## Goal

让背包、出战卡组和装备栏支持常见的修饰键快捷操作，减少玩家在整理技能卡与装备时必须拖拽的次数。

## Confirmed Facts

- 物品管理界面由 `InventoryUI` 绑定玩家背包、`BattleDeckComponent` 出战卡组和 `EquipmentComponent` 装备组件。
- 背包/卡组格子共用 `SlotUI`，当前只支持拖拽搬运。
- 装备槽由 `EquipmentSlotUI` 处理拖拽装备、卸下和槽位互换。
- `BattleDeckComponent` 只接收 `SkillCardData`，且会自动扩容并保留一个空槽。
- `EquipmentComponent.EquipFromInventory` 已支持从背包装备并替换目标槽位。

## Requirements

- Shift + 鼠标左键点击背包中的技能卡时，将该技能卡快捷加入出战卡组。
- Shift + 鼠标左键点击出战卡组中的技能卡时，将该技能卡快捷卸下到背包。
- Alt + 鼠标左键点击出战卡组格子时，将出战卡组中所有可卸下的技能卡快捷卸下到背包。
- Alt + 鼠标左键点击背包中的技能卡时，将背包中所有技能卡快捷加入出战卡组。
- Shift + 鼠标左键点击背包中的装备时，将该装备快速装备到可用装备栏；如果对应装备栏已有装备，则执行替换。
- 多槽位装备优先选择第一个可用空槽；没有空槽时替换第一个可装备槽。
- 快捷移动不应替换背包/卡组中不同种类的普通物品，避免批量操作把不相关物品换到来源格。
- 保留现有拖拽交互和 tooltip 行为。

## Acceptance Criteria

- [ ] 单张技能卡可通过 Shift + 左键在背包和出战卡组之间双向移动。
- [ ] Alt + 左键出战卡组可卸下所有能放入背包的技能卡。
- [ ] Alt + 左键背包技能卡可把背包内所有技能卡加入出战卡组。
- [ ] Shift + 左键背包装备可快速装备，并在目标槽已有装备时替换回原背包格。
- [ ] 快捷操作只处理技能卡或可装备物品；非技能、非装备物品无副作用。
- [ ] 现有背包、卡组和装备组件测试继续通过编译验证。

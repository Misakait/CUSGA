# 修复 CraftingUI 合成按钮无效

## Goal

定位并修复新 CraftingUI 的合成按钮事件和数量绑定，验证真实库存扣料与产出，同步文档。

## Requirements

- 修复新美术 CraftingUI 点击合成按钮没有执行的问题。
- 保持现有控制器分层、配方、材料与产出规则；数量必须为正整数。
- 界面正确绑定数量与合成按钮，材料不足或无配方时禁止执行。
- 合成数量和真实扣料/产出保持一致，库存变化后刷新可合成状态。
- 用已打开的 Godot 4.7.1 编辑器验证并同步关联文档。

## Acceptance Criteria

- [x] 新场景点击合成按钮触发 CraftingComponent，真实库存正确扣料与产出。
- [x] 默认数量为 1，可选择多次合成，耗尽材料后按钮禁用。
- [x] 没有配方时按钮禁用，执行不产生库存副作用。
- [x] 聚焦回归测试通过，CraftingUI 与 Main 场景运行无本次引入的脚本错误。
- [x] 文档准确说明控件绑定与合成数量规则。

## Notes

- 用户原话：“现在CraftingUI点击合成按钮后并不能合成，找一下原因，然后帮我修一下；自己建立任务自己完成”。任务建立及完成已获授权。
- 此项为现有 UI 小范围缺陷修复，采用 PRD-only。用户授权实施与验证，不执行 Git 提交或推送。

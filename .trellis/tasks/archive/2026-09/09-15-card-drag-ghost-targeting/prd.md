# 优化卡牌拖拽虚影目标选择

## Goal

将拖拽模式从“移动真实手牌”调整为“保留真实手牌、以跟随鼠标的卡牌虚影选择目标”。玩家在有效目标上松开鼠标后，虚影立即消失，原始手牌沿既有点击模式的行动展示链路飞向目标并完成结算。

## Confirmed Facts

- `scripts/card_scripts/card_manager.gd` 当前在 `_process` 中直接移动 `card_being_dragged`，并在 `finish_drag` 中将该真实节点交给 `DeckManager.play_card`。
- `DeckManager`、`BattleManager` 与 `CardAnimations.play_card` 已形成稳定的展示契约：同一张真实手牌在确认出牌后离开手牌布局，被存入 `Action.presentation_card`，再飞向明确的敌人目标。
- 拖拽期间的目标预览、目标类型判定、空白处对自身目标卡的施放规则、能量扣除和行动结算均已存在，不应因本功能改变。
- `SkillCard.tscn` 是完整卡牌展示节点；其 `Area2D` 会参与物理点击检测。因此虚影必须不参与鼠标/物理交互，不能抢占真实手牌或目标卡槽的命中。
- 关联玩法说明位于 `docs/游戏机制与玩法内容.md`；现有目标选择回归测试位于 `tests/godot/target_selection_visual_tests.gd`。

## Requirements

1. 仅在拖拽操作模式下，按住可用手牌时创建与该牌内容一致的临时虚影；真实手牌保持在其当前标准手牌位置，不随鼠标移动。
2. 虚影按既有拖拽偏移规则跟随鼠标，显示与原始卡牌一致的内容、固定 50% 不透明度，并承载原有拖拽缩放与目标选择视觉预览；它不得响应悬停、点击或物理查询。
3. 在有效敌人目标上松开鼠标时，先销毁虚影，再将真实手牌交给既有 `DeckManager → BattleManager → CardAnimations` 链路；真实卡牌从原始手牌位置飞向目标。
4. 在无效位置或手牌区松开时，销毁虚影，真实手牌保留在手牌布局；保留既有自身目标卡在手牌区外空白处施放的规则。
5. 切换操作模式、失去玩家回合或发生其他主动取消时，销毁虚影并清理目标预览，不产生能量消耗、行动或弃牌。
6. 不改变点击模式、目标类型解析、范围/随机/扩散结算、卡牌数值和既有飞行/命中动画参数。
7. 同步更新《游戏机制与玩法内容》，并为虚影生命周期与真实卡牌出牌链路补充聚焦回归覆盖。

## Acceptance Criteria

- [ ] 在拖拽模式按住可用手牌时，真实手牌位置不改变，屏幕上仅出现一个以 50% 不透明度显示、跟随鼠标的对应虚影。
- [ ] 虚影不会拦截真实卡牌和怪物卡槽的输入；目标预览与改动前一致。
- [ ] 在有效敌人目标上松开后，虚影消失，真实手牌从手牌区经既有动画飞向同一目标；能量、行动和弃牌各仅发生一次。
- [ ] 在无效位置或手牌区松开后，虚影消失且真实手牌保留在手牌区；自身目标卡仅在既有允许的手牌区外空白处施放。
- [ ] 切换模式、失去玩家回合或取消拖拽后，场上不残留虚影、目标高亮或输入状态。
- [ ] 点击模式以及自动、随机、范围、扩散和自身目标卡的既有结算语义不回归。
- [ ] 玩法机制文档与相关自动化测试反映新的拖拽交互。

## Scope Boundaries

- 不新增操作模式、全局单例、卡牌资源字段或动画时长配置。
- 不修改 `DeckManager`、`BattleManager` 或 `CardAnimations` 的既有行动展示契约，除非后续证据显示该契约无法支持真实手牌飞行。

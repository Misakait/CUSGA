# 抽卡界面悬停与选中动效照搬战斗系统

## Goal

把开局技能卡抽取界面的悬停与选中动态效果照搬战斗系统的卡牌视觉：悬停缩放 1.05（0.08s）并置顶，选中在此基础上位置抬升 36px（0.12s QUAD/EASE_OUT），悬停显示与战斗一致的卡名+描述浮窗；视觉参数提取为两边共享的配置，消除漂移。

## Requirements

### 悬停（鼠标移入 / 移出卡面）

- 卡面缩放 Tween 到 `Vector2(1.05, 1.05)`，时长 `0.08`；移出 Tween 回 `Vector2(1.0, 1.0)`。
- 悬停时卡面 `z_index` 置为 `2`，移出恢复 `1`。
- **不改变颜色**（战斗系统悬停不改 `modulate`，当前抽卡界面的 `modulate` 变色要移除）。
- 悬停时显示与战斗一致的提示浮窗（卡名 + 描述），移出时隐藏。

### 选中（点击卡槽切换）

- 选中：卡面位置上移 `36.0`，时长 `0.12`，`TRANS_QUAD` + `EASE_OUT`。
- 取消选中：卡面位置 Tween 回原位。
- **缩放由悬停驱动、位置由选中驱动**——这正是战斗的语义（`click_selected_card_lift_distance` 的注释明确说"独立于悬停缩放，确保玩家即使移开鼠标也能识别待确认卡牌"）。因此选中的卡在鼠标移开后不再放大，但仍抬升。
- 选中数量上限、第 3 张被拒、确认按钮启用条件等**既有交互规则全部不变**。

### 参数共享

- 战斗系统的卡牌视觉数值（正常 / 悬停缩放、缩放时长、选中抬升距离与时长、悬停层级）提取为**单一共享来源**，抽卡界面与 `CardManager` 都从它读取。
- 既有的可写性契约不得破坏：`CardManager` 的 `@export` 属性名必须保留（`tests/godot/target_selection_visual_tests.gd:106` 依赖 `set("scale_tween_duration", 0.0)`）。

### 浮窗在暂停下可用

- 抽卡界面处于暂停态（`get_tree().paused = true`），而 `TooltipPanel` 的延迟显示与跟随鼠标都跑在 `_process` 中、渐现依赖 Tween。必须让提示浮窗在暂停下正常工作，否则悬停提示永远不会出现。

## Acceptance Criteria

- [ ] 悬停卡面时，卡面 `scale` 在 `0.08` 秒内到达 `Vector2(1.05, 1.05)` 且 `z_index == 2`；移出后回 `Vector2(1.0, 1.0)` 且 `z_index == 1`。
- [ ] 悬停**不**改变卡面 `modulate`（保持 `Color(1,1,1,1)`）。
- [ ] 点击选中后，卡面 `position` 相对基准**上移 36px**（`0.12` 秒内完成）。
- [ ] 再次点击取消后，卡面 `position` 回到基准位置。
- [ ] 悬停卡面时提示浮窗显示该卡卡名与描述；移出后隐藏。
- [ ] 上述全部效果在抽卡界面处于暂停态下生效。
- [ ] 抽卡界面与 `CardManager` 的视觉数值取自同一来源；契约测试能捕获任何一处被单独改动。
- [ ] 既有交互验收（抽 5 张互不重复、必须选满 2 张、第 3 张被拒、未选不入背包、每局一次、不跨局累积）持续通过。
- [ ] 全量套件相对当前基线（372 passed / 2 个既有失败）无新增红灯。

## Notes

- 触发信号用 `Button` 的 `mouse_entered` / `mouse_exited`，而不是卡面的 `Area2D`：卡面被占位 `Button` 覆盖，`Button` 会优先消费 GUI 事件，`Area2D` 收不到 `mouse_entered`。视觉效果与战斗完全一致，只是触发来源不同。
- 浮窗文案取卡数据的 `DisplayName` / `DisplayDescription`（与卡面自身显示的文字同源），而不是战斗用的 `CardName` / `Description`，避免浮窗与卡面文字不一致。
- 本轮不做抽卡入场动画与拖拽视觉。

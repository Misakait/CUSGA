# 五行像素卡牌素材

素材使用本地绘制的 SVG，不含生成式图片、付费 API 或外部网络依赖。`build_assets.mjs` 是可编辑原稿：调色板、16×16 徽记和布局坐标均集中定义；Godot 直接使用 `res/skillcard/elemental/` 下的 SVG。该原稿目录用 `.gdignore` 排除，不进入游戏资源包。

## 素材清单

| 类型 | 数量 | 尺寸 | 文件 |
| --- | --- | --- | --- |
| 卡面底板 | 6 | 140×100 | `metal/wood/water/fire/earth/universal_front.svg` |
| 卡背 | 6 | 140×100 | 同前缀的 `_back.svg` |
| 卡胚物品图标 | 6 | 48×48 | 同前缀的 `_embryo.svg` |
| 技能卡库存图标原稿 | 5 | 32×32 | 五行前缀的 `_icon.svg` |
| 星形 | 1 | 12×12 | `star.svg` |

五行是金黄晶石、嫩绿叶芽、天蓝水滴、珊瑚火苗、杏橙岩块；通用卡胚使用紫色五行组合徽记。轮廓采用像素阶梯角，纸面保持浅色，让文字与费用易读。正面不烘焙具体技能名、费用、标签、星级或说明，避免素材和资源数据脱节。

## 游戏接入

- `core/skill_card_art.gd` 根据真实战斗技能的五行返回正面或卡背；未知属性使用通用版本。
- `SkillCard.tscn` 保留 **210×150** 的显示与碰撞范围（140×100 底板放大 **1.5 倍**）。五行决定卡框颜色，类别仅决定费用区颜色：攻击红、防御绿、状态蓝、未分类紫灰。
- 名称、五行、标签、费用／类别继续动态绑定；技能说明保留原悬停路径。名称默认 **18** 号、标签 **17** 号，长文字最小缩到 **12** 号。
- `skill_card_stars.gd` 显示实际 `StarLevel`，默认 **1 星**；**1～5 星**逐颗显示，超过 **5 星**显示一颗星和 `×实际数量`。单颗星 **12×12**，间距 **3**。
- 六个 `items/imprint/*_embryo.tres` 绑定各自图标。刻印标题栏直接读取物品图标，揭晓前显示当前池的五行卡背。
- 五张旧 `res/skillcard/*_skill_card.png` 保留原路径与 UID，只替换图像内容，因此已有技能卡和物品资源不需要逐个迁移。

## 编辑与重新导出

可以直接编辑 SVG。统一调整时，修改 `build_assets.mjs` 中的调色板、像素徽记或布局函数，然后在 Node.js 中调用导出的 `buildAssets({ fs, sharp, root })`：`fs` 为 `node:fs/promises`，`sharp` 为本地 sharp 库，`root` 为项目绝对路径。它会覆盖这套 SVG、五张库存 PNG，并生成 `preview.png` 素材总览；不会改动技能数据或其他美术资源。仅导出工具需要 sharp，游戏运行不依赖 Node.js。

# 五行怪物卡面

`build_assets.mjs` 是可编辑 SVG 原稿，复用技能卡的五行调色板。运行 `node art_sources/monster_cards/build_assets.mjs` 可重新导出全部 SVG；只使用 Node.js 自带模块，无需安装依赖。该目录通过 `.gdignore` 排除出游戏资源包。

## 卡面结构

六套卡面包括金、木、水、火、土、通用紫色，统一为 **100 × 140**，在场景中放大 **1.5 倍**，保持 **150 × 210** 的点击与选中范围。

- 顶部 **7～25** 像素为浅色名称铭牌，动态名称使用 **16** 号字体。
- **29～42** 像素为五行信息条，左侧显示“五行”，右侧显示真实五行文字。
- **45～128** 像素为浅色属性列表，物攻、法强、物抗、法抗、速度各占一行，名称左对齐、数值右对齐。属性名称字体 **14**，数值字体 **16**。五个独立的 **12 × 12** SVG 属性图标使用红、蓝、绿、紫、金配色，显示尺寸为 **14 × 14**。卡面只绘制信息分区与边框，不使用插画或图腾。
- 血条位于卡面上方，显示大小 **130 × 18**。状态栏沿用独立节点，行为预告使用下方 **84 × 24** 的深色标签和 **14** 号字体。

## 接入与维护

`scripts/card_scripts/monster_card_visual.gd` 挂在原有 `Sprite2D` 上。怪物初始化或重新初始化时，`entities/monster.gd` 的 `_update_card_ui()` 把真实五行交给 `ApplyElement()`，只切换贴图。未知五行和空数据回退到紫色通用版本。选择高亮、缩放、受击、生命、技能与伤害仍使用既有组件。

卡牌名称、五行文字、生命、属性和行为预告都由场景实时绑定，SVG 不保存这些动态数值。`monster_frame.svg` 是通用编辑器预览入口，运行时选择 `*_monster.svg`；两者都由生成脚本维护。截图 `ingame_preview.png` 用于查看真实战斗布局。

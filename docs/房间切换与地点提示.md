# 房间切换与地点提示

## 在哪里调整

在 Godot 的文件系统中打开 **`res://resources/map/room_transition_config.tres`**，在检查器展开各分组。这里统一控制跨房行动值成本与地点提示表现。修改后保存，重新运行游戏即可生效。场景 `res://scenes/map_scenes/map_control.tscn` 的 `RoomArrivalBanner` 实例使用这份资源；也可以在该节点的 `config` 字段替换视觉配置，但全局行动成本仍由 TimeSystem 读取默认资源，替换某个提示实例的配置不会更换全局成本来源。

| 检查器字段 | 默认值 | 含义 |
| --- | --- | --- |
| `action_cost` | 10 点行动值／次 | 每次成功跨房推进的时间；0 表示免费 |
| `enabled` | true | 地点提示开关；不影响行动值 |
| `show_initial_room` | false | 是否在开局、恢复房间时显示提示；初始房间始终免费 |
| `screen_y_ratio` | 0.24 | 下方房间提示的中心高度；720 高度时约 173 像素 |
| `biome_screen_y_ratio` | 0.10 | 上方生态提示的中心高度；720 高度时为 72 像素 |
| `banner_width` | 620 像素 | 房间文字和衬底最大宽度；窄窗口会留出两侧各 16 像素 |
| `biome_banner_width` | 760 像素 | 上方生态文字和衬底最大宽度 |
| `font` | `res://res/font/Uranus_Pixel_11Px.ttf` | 中文像素字体；留空使用项目默认字体 |
| `room_font_size` | 28 像素 | 下方房间名字号，跨生态时也使用此值 |
| `biome_font_size` | 48 像素 | 上方独立生态名字号 |
| `text_color` | `(1, 0.96, 0.85, 1)` | 正文暖白色 |
| `enter_duration` | 0.30 秒 | 文字淡入与上浮时长 |
| `room_hold_duration` | 1.40 秒 | 房间提示完全展开后的停留时间 |
| `biome_hold_duration` | 2.10 秒 | 生态提示完全展开后的独立停留时间 |
| `exit_duration` | 0.35 秒 | 淡出时长 |
| `rise_distance` | 8 像素 | 上浮幅度；0 表示只淡入 |
| `line_duration` | 0.45 秒 | 装饰细线从中心向两侧展开的时长 |
| `backdrop_opacity` | 0.32 | 横向渐隐的深色衬底透明度；0 表示无衬底 |
| `room_names` | 60 个中文地点名 | 内部场景标识 → 显示名称；例如 `ancient_tree` → `远古巨树` |
| `biome_names` | 木／土／水／火／金之生态、原野 | 生态标识 → 上方独立生态名 |
| `biome_colors` | 木 `#a6d695`、土 `#e0bb87`、水 `#8ecfe4`、火 `#eea080`、金 `#ebd186`、原野 `#d8d3b8` | 装饰细线颜色 |

这些数值的单位为 1280×720 基准视口中的像素与秒。两条提示分别计算 `max(enter_duration, line_duration) + 各自的 hold_duration + exit_duration`，因此房间提示默认 **2.20 秒**，生态提示默认 **2.90 秒**。动效采用单向淡入、短距离上浮与细线展开，不缩放文字、不晃动相机。入场使用三次缓出位移与正弦缓出透明度，退场使用正弦缓入透明度。实际入场、细线展开与退场时长最低均为 0.05 秒，停留时间最低为 0 秒，位移最低为 0 像素；房间高度比例限制在 0.10～0.50，生态高度比例限制在 0.05～0.40，衬底透明度限制在 0～0.80。两条标题各自单行显示，超长时省略。调整位置时应保持生态提示在房间提示上方，并留出容器高度所需的间距。

文字描边为 4 像素，颜色 `(0.04, 0.05, 0.06, 0.85)`；阴影向下 2 像素，颜色 `(0.02, 0.03, 0.04, 0.8)`。房间容器高 80 像素，生态容器高 96 像素，两侧各留 16 像素；房间细线宽 200、高 2 像素，生态细线宽 280、高 3 像素，都从 18% 宽度展开。上述固定视觉结构在 `res://scenes/ui_scenes/room_arrival_banner.tscn` 调整，两个容器分别为 `Root/Banner` 与 `Root/BiomeBanner`。

## 行动值规则

这里消耗的是**局外时间，即行动值**，通过 `TimeSystem.PassMapMoveTime()` 推进昼夜、天数及相关时间事件。不会消耗战斗能量或角色体力。每个昼／夜阶段仍为 100 点，每天共 200 点；默认成功移动 10 次推进一个阶段。跨生态属于一次普通跨房，仍只消耗一次成本。

唯一结算入口是 `UIMapWorldController.request_room_transition(position)`。目标经过 Model 校验且坐标确实改变后才收费；初始房间、重复进入当前房间、越界、非相邻、单向或没有连接、目标资源缺失均不收费。同步信号回调内的重复进入请求会被拒绝。走回旧房间是一次真实移动，正常收费。当前没有冷却豁免或抖动豁免。

门传送 `DoorController` 和旧方向按钮也通过 `MapInstantiator.load_scene_at` 路由到同一 Controller，因此自身不再提前扣费。旧按钮仍读取最终的 `TimeSystem.MapMoveTimeCost` 计算长按时长，默认 `10 / 10 = 1.0 秒`；当前无缝探索直接行走跨界，无额外长按等待。

`TimeSystem.MapMoveTimeCost` 在 Autoload 创建时从共享配置的 `action_cost` 读取。运行中可用 `TimeSystem.SetMapMoveTimeCost(25)` 临时改为 25 点，用 `SetMapMoveTimeCost(0)` 改为免费，负数被忽略。运行时覆盖优先于资源初值，不写入存档；下次启动重新读取资源。修改配置资源的成本不会在已经运行的游戏中自动重置临时覆盖。

## 提示触发与复用

`RoomArrivalBanner` 监听地图根节点的 `on_entered_room(position, scene)`，只响应实际进入的房间；3×3 窗口的预加载房间不显示提示。房间名称读取 `MapWorldModel.get_scene_resource(position).scene_name`，生态读取 `MapTypes.scene_biome`，不通过翻译后的文字猜测生态。

同生态换房只更新下方房间提示，例如 `远古巨树`。跨生态时同时启动两条独立提示：上方为 `土之生态`，下方为 `化石断崖`。即使两间房使用同一种地形场景，只要坐标不同也会播放房间提示。内部场景标识不改名，只在 `room_names` 中调整显示文字。未登记名称时去掉末尾数字层级后缀 `_t1` 等，并把下划线转换为空格；新增生态可补齐名称和颜色映射。

房间与生态分别持有 Tween（补间动画）和结束回调。连续换房只替换下方房间提示，仍在播放的生态名会按自己的时间结束；再次跨生态才替换上方生态名。两条提示均不排队、不叠加，旧回调不会收起新标题。动画随游戏暂停而暂停；打开大地图或暂停菜单不会穿透到其上方。该组件使用 CanvasLayer **1**，高于昼夜滤镜 **0**、低于主 HUD **2** 与大地图 **3**。探索世界隐藏时两条提示一起收起。所有界面节点均忽略鼠标事件，不抢占移动和点击。

可在其他地图根节点下实例化 `res://scenes/ui_scenes/room_arrival_banner.tscn`。宿主需提供进入房间信号、`MapWorldModel` 与 `MapTypes` 子节点；`map_control_path` 默认 `..`。也可直接调用 `show_arrival(room_name, biome_id, biome_changed = false)` 复用文字动画，不会推进时间。参数依次为显示房间名、生态内部标识、是否同时启动上方生态提示；无返回值。传入 false 只更新房间文字，不会中断已有生态提示。

## 验证

编辑器 MCP 套件 `room_transition` 的 5 项测试、84 项断言通过；在新启动的游戏进程中执行同一套测试也通过，以避免编辑器旧脚本缓存影响结论。覆盖成功／重复／失败／信号重入的扣费、真实时间系统的零成本和昼夜边界，以及 60 个房间名称。相关测试路径为 `res://tests/godot/test_room_transition.gd`。

行动值运行验证覆盖了玩家位置跨界一次推进 10 点、后续 10 帧停留和非法目标均不推进，以及木生态连续跨 10 个房间到土生态共推进 100 点。分离提示的运行验证覆盖：普通换房只显示房间名；跨生态显示独立的“土之生态”和“化石断崖”，字号分别为 48 与 28、上下容器无重叠；普通换房不重新启动生态动画；房间名先结束时生态名仍显示，最终两者各自隐藏。Main 主场景的真实跨生态事件也验证通过，上方显示“土之生态”、下方显示“水晶洞窟”，当前运行日志无错误和警告；验证后游戏已停止，编辑器保持打开。

测试器枚举全部套件时仍会报告原有 `test_item_room_content.gd` 的加载问题；该问题不是本功能引入，也不影响上述聚焦测试通过。

# 游戏机制与玩法内容

## 战斗卡牌操作模式

战斗场景提供两种玩家卡牌操作模式：

- 点击：默认模式。玩家先点击手牌，已选卡牌会向上移动；再次点击同一张卡牌可取消整次选择。玩家可再点击一名敌人；再次点击同一敌人只取消敌人目标，卡牌保持选中。最后点击手牌区正上方的“确定”按钮施放。没有选择敌人时，施放目标是玩家自身。“取消”、改选卡牌、切换模式或失去玩家回合时，卡牌会恢复正常手牌位置，且不消耗能量、不移除卡牌。
- 拖拽：保留原有规则。玩家按住手牌并拖到敌人的卡槽区域后松开，以该敌人为目标施放；原有的自身目标卡牌仍可按既有空白处释放规则使用。

操作模式属于玩家偏好，不是战斗数值或卡牌资源数据。首次运行、配置缺失或配置无法读取时，默认使用“点击”模式。玩家在战斗右上角的“设置”面板切换模式后，选择会写入 `user://settings.cfg` 的 `battle/operation_mode`，因此会跨战斗和游戏重启保留。

## 目标与范围规则

点击模式仅把场上怪物的卡槽识别为显式敌人目标。未命中怪物卡槽时，确认操作会将玩家自身传入卡牌行动。卡牌固有的目标类型（例如全体敌人、随机敌人、扩散目标）仍由现有战斗结算逻辑展开；其中随机敌人卡牌会在本次行动开始时从当前敌人中随机一次，忽略点击或拖拽时点中的敌人，并将该同一结果用于表现与效果结算。操作模式不改变卡牌效果、敌人 AI、伤害或任何战斗数值。

## 目标选择视觉反馈

当玩家点击选择或拖拽一张可用卡牌时，场上敌人怪物卡会根据该卡的目标类型显示局部视觉状态。该系统只影响卡面、名称、属性和状态栏，不缩放或变暗生命条；它不会修改目标合法性、选中顺序、随机结果、能量消耗或卡牌结算。

默认表现参数统一由 `CardManager` 的 Inspector 导出字段配置：怪物卡正常缩放为 `1.50`；可手动指定目标时，可选敌人在 `1.53` 与 `1.56` 之间循环呼吸，单程时长为 `0.50` 秒；鼠标悬停缩放为 `1.60`；主选中缩放为 `1.66`；次级选中缩放为 `1.60`。已选中目标显示宽度 `3px`、颜色 `Color(0.25, 1.00, 0.35, 1.00)` 的绿色边框。不可选目标恢复 `1.50` 缩放，并以 `Color(0.45, 0.45, 0.45, 1.00)` 的颜色倍率变暗。静态状态切换继续使用 `0.08` 秒缩放过渡。

- 单体敌人和任意单体卡：所有在场敌人都是可选目标并呼吸；点击模式中鼠标悬停目标仅放大，点击后成为带绿色边框的主选中目标；拖拽模式中悬停合法目标即预览主选中状态。
- 扩散敌人卡：主目标采用主选中缩放和绿色边框；左右相邻敌人采用较小的次级选中缩放和绿色边框。
- 全体敌人、随机敌人与全体单位卡：所有受影响的敌人直接作为自动选中目标显示绿色边框，不播放呼吸动画。随机敌人的实际结算目标仍按原规则在行动开始时随机一次。
- 自身目标卡：所有敌人怪物卡均变暗；玩家血量、能量和属性 UI 不新增目标边框、缩放或呼吸效果。

取消选择、改变操作模式、松开拖拽卡牌、失去玩家回合或目标离场时，目标选择表现会被清理，所有怪物卡恢复正常颜色、无绿色边框且不再播放呼吸动画。

## 卡牌施放与命中反馈

向明确选中的场上怪物，或向本行动随机确定的场上怪物施放玩家卡牌时，卡牌会依次执行以下表现：

1. 脱离手牌布局并飞向目标怪物。
2. 目标短暂抖动并闪白，作为命中打击反馈。
3. 按既有规则结算卡牌效果。
4. 卡牌只在此后写入弃牌堆，再沿用既有弃牌渐隐并销毁。

受击反馈先于卡牌效果结算：怪物可能被伤害同步移出场景树，先完成反馈能保证行动队列不会等待已删除节点的动画。受击内部的抖动与闪白同时启动；两者的完成信号是一次性的，行动队列只能等待仍在运行的 Tween，不能在较长动画结束后再等待较短动画已经发射过的信号。随机敌人卡牌已经有唯一确定的实际目标，因此也播放该单体反馈；对自身施放，或卡牌的效果属于全体、扩散等没有单一明确敌人目标的情况，不会强行飞向任意敌人，也不会播放单体受击反馈。目标已失效或进入删除队列时也会跳过该表现，但卡牌仍会在行动完成时仅一次进入弃牌堆。行动队列持续负责锁定输入与控制结算顺序。

## 数值记录

本机制未新增或调整伤害、能量、冷却、概率、持续时间等战斗数值。选中上移距离和动画时长仅为 `CardManager` 可调的表现参数；飞行与命中继续复用既有 `CardAnimations` 动画参数。

# 游戏机制与玩法内容

## 战斗卡牌操作模式

战斗场景提供两种玩家卡牌操作模式：

- 点击：默认模式。玩家先点击手牌，再可选地点击一名敌人，最后点击手牌区正上方的“确定”按钮施放。没有选择敌人时，施放目标是玩家自身。“取消”会放弃当前选择，不消耗能量，也不会移除卡牌。
- 拖拽：保留原有规则。玩家按住手牌并拖到敌人的卡槽区域后松开，以该敌人为目标施放；原有的自身目标卡牌仍可按既有空白处释放规则使用。

操作模式属于玩家偏好，不是战斗数值或卡牌资源数据。首次运行、配置缺失或配置无法读取时，默认使用“点击”模式。玩家在战斗右上角的“设置”面板切换模式后，选择会写入 `user://settings.cfg` 的 `battle/operation_mode`，因此会跨战斗和游戏重启保留。

## 目标与范围规则

点击模式仅把场上怪物的卡槽识别为显式敌人目标。未命中怪物卡槽时，确认操作会将玩家自身传入卡牌行动。卡牌固有的目标类型（例如全体敌人、随机敌人、扩散目标）仍由现有战斗结算逻辑展开；操作模式不改变卡牌效果、敌人 AI、伤害或任何战斗数值。

## 数值记录

本机制未新增或调整伤害、能量、冷却、概率、持续时间等数值。

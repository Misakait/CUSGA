# 怪物掉落池

每个怪物的 `drop_pool` 是独立的 `MonsterDropPool`，不会从战斗技能或技能卡自动生成。已有怪物的旧技能卡掉落已经移除；默认池为空，需要在怪物资源中配置。

在 Godot 检查器中打开怪物的 `drop_pool`，设置 `draw_count`（默认 5），再向 `entries` 数组添加 `MonsterDropEntry`。每个条目的 `drop_item` 选择物品 Resource，`drop_weight` 设置非负整数。需要“什么都不掉”时，添加一个物品留空、权重大于 0 的条目。每次抽取按正权重计算比例，抽后放回；零或负权重被忽略，空池和总权重为 0 时返回空结果。每次抽中物品产生一件，重复抽中可产生多件。

例如木头 50、木卡胚 50、通用卡胚 10、空 50，总权重为 160。单次概率为 31.25%、31.25%、6.25%、31.25%；默认五次抽取相互独立，不保证每场都掉落物品。示例不是默认配置。

怪物初始化时把池交给 `LootComponent`；死亡只触发一次 `RollLoot`，结果通过现有掉落事件交给单场战斗的收集组件。胜利时收集组件调用 `BoardController.SpawnLootCards`，以玩家世界位置为起点生成原有可拾取掉落；失败不投放。地形采集与建筑拆除仍使用 `LootTableData` 和 `LootDrop`，不受怪物加权池影响。
